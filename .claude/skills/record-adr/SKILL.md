# Skill: record-adr

Зафіксуй рішення: **$ARGUMENTS**

## Процедура

1. **Зрозумій рішення.** Визнач: що вирішено (одне речення), чому (контекст, обмеження), що
   розглядалося замість. Якщо в репозиторії є код чи документ, на якому ґрунтується рішення, прочитай
   його (`Read`) і запам'ятай коміт (`source`). Нічого не вигадуй: альтернативи — лише ті, що
   випливають з контексту; якщо їх не названо, напиши «інші варіанти не розглядалися».
2. **Перевір дублікати й конфлікти** (лише через `fridge-kb`, прямий доступ до vault — B-02):
   `search_notes(<ключові слова>, type: "decision")`, `get_note` для схожих.
   - Таке саме рішення вже є → не створюй нове, повідом id наявного.
   - Нове рішення **замінює** наявне → `supersedes: [[ADR-NNNN …]]` і окремим викликом онови старе: `status: superseded`.
3. **Визнач `applies_to`** — компоненти й концепції, до яких застосовується рішення
   (онтологія: decision → component | concept, щонайменше одна ціль). Назви бери лише з результатів
   `search_notes` / `get_note`, не з пам'яті.
4. **Сформуй вміст** за шаблоном [adr-template.md](adr-template.md). Номер ADR і префікс назви
   `ADR-NNNN` призначає сервер — у `title` передай лише суть рішення.
5. **Пробний запис:** `ingest_note` з `type: "decision"`, `status: "accepted"`,
   `fields: { applies_to, supersedes?, deciders: ["Милькус Павло"] }`, `dry_run: true`.
   Помилка онтології чи посилань → виправ і повтори (до 3 спроб).
6. **Запис:** той самий `ingest_note` без `dry_run`. Це W-05 — Claude Code попросить
   підтвердження людини. Не обходь його і не записуй іншим способом; якщо підтвердження не надано —
   заверши звітом зі статусом «очікує підтвердження» і готовою чернеткою.

## Формат результату

```
## Звіт record-adr
Рішення: <одне речення>
ADR: <ADR-NNNN Назва> (id adr-NNNN) — <created | unchanged | очікує підтвердження>
applies_to: <[[…]], …>   supersedes: <[[…]] | —>
Дублікати / конфлікти: <немає | перелік з id>
Коміт vault: <hash | —>
Guardrails: B-02 (лише MCP), W-05 (<підтверджено | не підтверджено>), онтологія — dry_run пройдено
```
